Pagamento

Escolha o gateway do Pix. Antes de trocar, o painel testa as credenciais; se falhar, nada muda. Pedidos já criados continuam no gateway em que nasceram.

Credenciais da SyncPay

Deixe em branco para continuar usando as credenciais que já estão no banco.

Credenciais do Mercado Pago

No Mercado Pago: Seu negócio → Configurações → Credenciais → Credenciais de produção → Access Token (começa com APP_USR-). O aviso de pagamento é configurado sozinho em cada Pix.

Pixel e anúncios

Com o Pixel o site envia PageView, ViewContent, InitiateCheckout e Purchase. Com o token da API de Conversões, a compra também é enviada pelo servidor na hora em que o Pix cai — mesmo se a pessoa pagar pelo app do banco e não voltar ao site.

Onde achar: Gerenciador de Eventos → seu conjunto de dados → Configurações. O ID fica no topo; o token, em “API de Conversões → Gerar token de acesso”. O código de teste fica na aba “Testar eventos”.
